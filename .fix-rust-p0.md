We need to fix 4 P0 Rust issues found in code review. Make these changes:

## P0-1: WriteChannel::flush deadlock (engine.rs:301-306)
Replace std::sync::mpsc with tokio::sync::oneshot and make flush async:

OLD:
```rust
pub fn flush(&self) -> Result<(), String> {
    let (tx, rx) = std::sync::mpsc::channel();
    self.sender.send(WriteOp::Flush { done: tx }).map_err(|_| "channel closed".to_string())?;
    rx.recv().map_err(|_| "flush failed".to_string())
}
```

NEW:
```rust
pub async fn flush(&self) -> Result<(), String> {
    let (tx, rx) = tokio::sync::oneshot::channel();
    self.sender.send(WriteOp::Flush { done: tx }).map_err(|_| "channel closed".to_string())?;
    rx.await.map_err(|_| "flush failed".to_string())
}
```

Also update WriteOp::Flush to use tokio::sync::oneshot::Sender<()>.

## P0-2: Mutex poisoning silently ignored
Replace all `if let Ok(x) = mutex.lock()` with `mutex.lock().unwrap_or_else(|e| { tracing::error!("lock poisoned"); e.into_inner() })` in engine.rs for:
- cancel_tx (IndexScheduler)
- wiki_dir_mtime
- memory_dir_mtime
