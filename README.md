# Wiki Memory Engine (wm)

A local knowledge graph engine for AI-assisted project management. **wm** provides an MCP server that indexes markdown wiki pages into a typed graph with BM25 search, optional semantic search via ONNX embeddings, and a full CLI/TUI for interactive use.

## Install

```bash
npm install -g @something-cabinet/wm-cli
```

## Quick Start

```bash
# 1. Initialize a project
wm-cli init

# 2. Start the MCP server (for AI agents)
wm-cli mcp

# 3. Or use the interactive TUI
wm-cli
```

## Setup Workflow

### 1. Initialize

```bash
wm-cli init                    # Interactive wizard — prompts for model, git tracking, platforms
wm-cli init --no-wizard        # Headless — use defaults
wm-cli init my-project         # Name the project
```

The interactive wizard asks:
- **Enable semantic search?** → Select ONNX embedding model (bge-small-en-v1.5 / all-MiniLM-L6-v2 / bge-base-en-v1.5)
- **Git tracking mode?** → `git-tracked` (track all) / `git-ignored` (ignore generated files) / `none`
- **Platform agent files?** → Generate configs for Claude Code, OpenCode, Kiro, Gemini, Copilot, or generic agents

### 2. Generate Platform Config

```bash
wm-cli setup claude            # .mcp.json + .claude/skills/
wm-cli setup opencode          # opencode.json
wm-cli setup codex             # .codex/config.toml
wm-cli setup all               # All platforms
```

This generates MCP configs so AI agents can connect to `wm-cli mcp`.

Optional: Run wm-cli index rebuild (AI agent may run this)
- Rebuild BM25
- Rebuild Wiki (if someone in your project did this)
- Rebuild code index

### 3. Usage

Innate skill from the skills set

init -> spec -> extract -> commit

### 4. Semantic Search (Optional)

```bash
wm-cli model download bge-small-en-v1.5    # Download ONNX model (~134MB)
wm-cli index embed                          # Build embedding vectors
```

Once embedded, search uses hybrid BM25 + cosine similarity:
```bash
wm-cli search "how does authentication work" --mode hybrid
```

Without a model, search falls back to keyword-only BM25 gracefully.

### 5. Agent Integration

Agents connect via MCP over stdio:

```json
// .mcp.json (auto-generated by wm-cli setup)
{
  "mcpServers": {
    "wiki-mem": {
      "command": "wm-cli",
      "args": ["mcp"]
    }
  }
}
```

Claude Code slash commands: `/wm-init`, `/wm-plan`, `/wm-implement`, `/wm-search`, `/wm-extract`, `/wm-flow`, etc.

## Architecture

```
wm-core/              # Library — graph engine, search, MCP tools
wm-cli/               # CLI binary — clap + Ratatui TUI

.wm/
  config.json         # Project configuration
  wiki/               # Markdown wiki pages with YAML frontmatter
    concepts/
    decisions/
    howto/
    patterns/
    reference/
    specs/
    tasks/
  memory/             # JSON memory entries (gitignored by default)
  state/
    vectors.bin       # ONNX embedding vectors (gitignored, ~134MB)
```

### Page Types

| Type | Directory | Purpose |
|------|-----------|---------|
| task | `wiki/tasks/` | Actionable work units with ACs |
| spec | `wiki/specs/` | Requirements and goals |
| concept | `wiki/concepts/` | Domain concepts and architecture |
| pattern | `wiki/patterns/` | Reusable solutions |
| decision | `wiki/decisions/` | ADRs with context and rationale |
| howto | `wiki/howto/` | Step-by-step guides |
| reference | `wiki/reference/` | API docs, config tables |

### Search Modes

| Mode | Description |
|------|-------------|
| `keyword` | BM25 with field-weighted scoring + code-aware tokenizer |
| `semantic` | Cosine similarity via ONNX embeddings |
| `hybrid` | RRF fusion of BM25 + cosine (default) |

### Graph

Pages are connected via typed edges from `relates_to` frontmatter:

```yaml
relates_to:
  - {type: extends, target: "wiki:concepts:base-auth"}
  - {type: implements, target: "wiki:specs:auth-v2"}
```

49 tools exposed to AI agents via MCP. Key groups:

| Prefix | Tools |
|--------|-------|
| `wm_project.*` | initial, help, status, detect, set |
| `wm_search.*` | query, retrieve, resolve |
| `wm_page` | Consolidated CRUD + link/unlink (get, create, list, update, delete, link, unlink) |
| `wm_graph.*` | neighbors, stats, full, subgraph, path |
| `wm_task` | Consolidated task ops (board, list, create, get, update, check_ac, uncheck_ac, subtask) |
| `wm_memory` | Consolidated memory ops (list, get, add, update, delete, promote) |
| `wm_template` | Consolidated template ops (list, get, create, run) |
| `wm_time` | Consolidated time ops (start, stop, add, report) |
| `wm_model` | Consolidated model ops (list, status, download, remove) |
| `wm_source` | Consolidated source state machine (add, process, complete, list, verify, discover, remove, status) |
| `wm_decision` | Consolidated decision ops (create, get) |
| `wm_ref.*` | extract, resolve, resolve_all |
| `wm_code.*` | search, symbols, deps, file |
| `wm_lsp.*` | definition, references, hover, status, implementations, workspace_symbols, diagnostics, rename |
| `wm_index_*` | rebuild, status, embed |
| `wm_version.*` | list, get, rollback |
| `wm_log.*` | recent, since, filter |
| `wm_lint.*` | check, fix |
| `wm_validate.*` | check |
| `wm_skill.*` | trigger |

Run `wm-cli mcp` and call `wm_help` for the authoritative tool list.

## Configuration

`.wm/config.json`:

```json
{
  "project_name": "my-project",
  "embedding": {
    "model_name": "bge-small-en-v1.5"
  },
  "search": {
    "default_mode": "hybrid",
    "default_limit": 20,
    "rrf_k": 60,
    "scoring": {
      "field_weights": { "title": 4.0, "body": 1.0 },
      "recency_model": "fsrs",
      "recency_stability_days": 7,
      "memory_salience_boost": 2.0,
      "memory_salience_clamp": 0.1
    }
  }
}
```
