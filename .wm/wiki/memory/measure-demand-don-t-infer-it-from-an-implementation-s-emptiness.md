A 'no demand' verdict was drawn from an unbuilt, wrong-typed artifact. Measuring the requirement independently (what behaviour would this remove?) reversed it in one command — four names for one rule, same-name content differing 4x. Evidence of absence in one artifact is not absence of need in the class. Full reference: @wiki/concepts/failure-demand-inferred-from-implementation-absence
