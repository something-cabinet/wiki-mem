## UI Review Findings — wm-web (Angular 22)

### P0 — Critical

#### 1. Duplicate :root and :root.dark blocks in styles.css
- Lines 19-53 define light theme (neutral hue 0), then lines 160-192 redefine it with hue 285.823
- Second block wins by cascade but first block has sidebar vars and --success the second is missing
- Same duplication for dark mode (lines 56-89 vs 194-223)
- @layer base block also duplicated (lines 148-157 vs 225-232)
- **File:** apps/wm-web/src/styles.css

#### 2. Tags input in Memory create dialog never sent
- newTags field collects comma-separated tags from user
- createEntry() never reads this.newTags — only calls createPage() without tags
- Tags are silently discarded
- **File:** apps/wm-web/src/app/views/memory/memory-view.component.ts:147-153

### P1 — High

#### 3. No edit/delete for pages or memory entries
- Pages view: list is clickable to view, but no edit or delete action
- Memory view: read-only card display, no edit or delete
- **Files:** apps/wm-web/src/app/views/pages/pages-view.component.ts, apps/wm-web/src/app/views/memory/memory-view.component.ts

#### 4. Pages create dialog has no content/body field
- Dialog has Path, Title, Type — no content textarea
- createPage() called with empty string for content
- **File:** apps/wm-web/src/app/views/pages/pages-view.component.ts:45-71

#### 5. No pagination or search in pages list
- listPages() loads every page into a flat grid
- With 200+ wiki pages this is unusable
- **File:** apps/wm-web/src/app/views/pages/pages-view.component.ts:81-94

### P2 — Medium

#### 6. Hardcoded colors everywhere — breaks dark mode
- Search: text-gray-400, text-blue-700, bg-slate-100
- Tasks: border-gray-200, text-gray-500, bg-gray-50
- Pages: text-blue-600, bg-slate-50, border-gray-200
- Memory: text-gray-500, text-gray-400
- Settings: text-gray-500, border-gray-100
- Only Graph view uses theme tokens
- **Files:** All 6 view components

#### 7. Inline SVGs vs ng-icon inconsistency
- Layout uses ng-icon/lucide system
- All views use raw inline SVGs instead
- **Files:** All views except graph

#### 8. No error handling on several API calls (✅ Fixed)
- All 6 views now have error handlers on every subscription
- IPC timeout (15s) added to ApiService so calls don't hang forever

#### 9. No subscription cleanup (✅ Fixed)
- DestroyRef + takeUntilDestroyed added to all 6 views: Search, Graph, Tasks, Pages, Memory, Settings

#### 10. Settings page is purely a status dashboard
- No actual settings (dark mode toggle, sidebar prefs, search defaults)

### P3 — Low

#### 11. Shared spinner component missing
- Same inline spinner template duplicated in all 6 views

#### 12. Graph canvas has no aria-label
- No aria-label or role="img" on canvas

#### 13. Search has no debounce
- API call fires on every Enter keypress, no cancellation

#### 14. No keyboard focus indicators on clickable cards
- Pages list items: cursor-pointer but no tabindex or focus styles
- Memory cards: no focus indicator

#### 15. Graph hover tooltip never clears
- onNodeHover updates tooltip but no onMouseLeave to clear it

### What's Good
- Clean separation of views, layout, and services
- Consistent spartan-ng @ui/* barrel imports
- Proper scrollbar hiding utility
- OKLCH theme system with proper CSS variables (just duplicated)
- API service with good Tauri vs HTTP dual-path
- All standalone components with explicit imports
- Search view has proper aria-labels and list roles
