## Goal

Remove every comment (`//`, `///`, `//!`, `/** */`, `/* */`) from all Rust and TypeScript source files per the updated no-comments rule.

## Scope

~60 files, ~1000 comment lines across `apps/wm-cli/`, `apps/wm-core/`, `apps/wm-server/`, `apps/wm-web/src/`.

## Approach per comment type

| Type | Action |
|------|--------|
| `// ─── Section markers ───` | Delete — the code structure (module split, fn boundaries) already conveys this |
| `// Field labels` (`// Dashboard scroll`, `// Skill system`) | Delete — the named type/field already conveys meaning |
| `// Explanatory` (`// Clear canvas`, `// Draw edges`) | Extract into named function or delete if obvious from code |
| `// TODO:` | Create WM task, delete comment |
| `/// Doc comments` | Rename function to be self-documenting, or delete if restating the obvious |
| `//! Module docs` | Delete — module content is self-evident from imports and types |
| `/** */ JSDoc` | Delete on private fields; rename public API if needed |

## Status — DONE (partial per ratified decision)

All inline `//` comments stripped from production Rust and TypeScript source in scope (203 Rust lines across 44 files; 12 TS `//` lines + 11 `<!-- -->` template markers). Per the ratified decision (`@wiki/decisions/zero-comments-extract-over-document` ratified as "no-comments rule targets inline comments"), doc comments are EXEMPT: rustdoc `///`/`//!` and JSDoc `/** */` are kept. `#[allow(...)]` attribute reasons and `// @ts-ignore` directives are functional, kept. Comments inside `#[cfg(test)]` mods and `tests/` are exempt per repo convention (65 test-mod lines remain). Verified: `cargo check --workspace`, `cargo clippy -p wm-core/-p wm-cli/-p wm-server -- -D warnings`, and `tsc --noEmit` all pass.
