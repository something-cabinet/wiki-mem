Replace the single spinning icon with content skeletons that match the page layout shape. Use hlm-skeleton from spartan-ng. This gives users a mental model of what's loading.

## Implementation notes (done 2026-08-08)
- `@spartan-ng/ui-skeleton-brain/helm` is NOT installed in this repo, so a lightweight `wm-skeleton` component was created at `apps/wm-web/src/libs/ui/skeleton/` (pulsing `bg-muted` block, `class` input; same convention as `wm-spinner`). Registered as `@ui/skeleton` in `tsconfig.json`.
- Loading states replaced/paired with content-shaped skeletons in tasks (accordion-column grid), pages (list rows), memory (entry cards), search (result cards), and graph (node-cluster preview). Spinner kept as a small companion indicator where it reads naturally (graph overlay).
- Loading blocks carry `role="status"` / `aria-live="polite"` / `aria-busy="true"` with sr-only text.
- Verified: `tsc --noEmit` and `ng build` pass.
