  # Audit: BM25 rebuild path consistency (CLI vs MCP)

  ## Description

  `rebuild_from_engine()` in `apps/wm-cli/src/main.rs` now rebuilds the BM25 index after graph snapshot rebuild. But the MCP `WmIndexAction::Rebuild` in `apps/wm-core/src/mcp/tools/index.rs` also triggers a rebuild — verify it calls the same path (or consolidates). Both code paths should rebuild BM25; otherwise the MCP rebuild won't update the search index.

  ## Location

  - `apps/wm-cli/src/main.rs` — `rebuild_from_engine()`
  - `apps/wm-core/src/mcp/tools/index.rs` — `WmIndexAction::Rebuild`

  ## Acceptance Criteria

  - [ ] Trace the MCP index rebuild path to see if it calls BM25 rebuild
  - [ ] If not, add BM25 rebuild to the MCP handler
  - [ ] Consider consolidating into a shared function in `wm-core`
