Wire the graph spacing slider to control fjadra global repulsion (ManyBody strength) instead of per-link distance. Add spacing field to ComputeLayoutPayload in Rust. Debounce slider changes and trigger recompute.

## Implementation notes (done 2026-08-08)
- Added `charge_strength: f64` to `SimulationHandle.create` in `packages/fjadra-wasm/src/lib.rs`, applied to `ManyBody::default().strength(charge_strength)`. Default hardcoded `-200.0` removed.
- Regenerated wasm bundle into `apps/wm-web/src/assets/wasm` (`wasm-pack build --target web`); wrapper `.d.ts` regenerated with the new param.
- `graph-view.component.ts` now passes `SLIDER_TO_CHARGE(linkDistance)` (=-round(v*1.1111): slider 50→-56, 180→-200≈previous default, 400→-444). The slider drives BOTH link distance and global repulsion, so it spreads/tightens ALL nodes (connected + unconnected).
- Debounced recompute (150 ms) via `spacingTimer`; layout restarts with `skipFit` so the user's viewport is preserved.
- Verified: `tsc --noEmit`, `ng build`, `cargo check -p fjadra-wasm` all pass.
