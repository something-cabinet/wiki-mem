## Bug Description

`wm_memory.add` always returns `INVALID_ACTION` error regardless of action parameter value.

**Tool:** `wm_wm_memory_add`

**Attempts:**
- `action: "add"` — "Unknown action. Valid actions: wm_memory.add"
- `action: "wm_memory.add"` — "Unknown action. Valid actions: wm_memory.add"
- No action — "Unknown action. Valid actions: wm_memory.add"

**Successful earlier call** (same session, before .wm/AGENTS.md was deleted):
```
{"action":"add","id":"canvas2d-wasm-graph","title":"...","content":"...","layer":"project","tags":[...]}
```
This worked. The tool broke after `.wm/AGENTS.md` was deleted.

**Workaround:** Write memory `.md` files directly to `.wm/wiki/memory/` and run `wm_index rebuild`.

**Reproduction:**
1. Call `wm_wm_memory_add` with `{"action":"add","id":"test","title":"test","content":"test","layer":"project"}`
2. Observe error
