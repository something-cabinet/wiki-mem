# Consider: replace glob re-exports with individual exports in `models/mod.rs`

## Description

All glob re-exports in `packages/wm-engine/src/models/mod.rs` use `#[allow(ambiguous_glob_reexports)]` — necessary after Rust 2024 edition tightened re-export rules. Consider whether individual exports (one `pub use` per type) would be cleaner for a crate boundary, even if more verbose. This improves:
- Explicit API surface (consumers know exactly what's available)
- No need for suppression attributes
- Better documentation generation

## Location

`packages/wm-engine/src/models/mod.rs`

## Acceptance Criteria

- [ ] Evaluate number of exported types per file (is it manageable?)
- [ ] Decide: keep glob re-exports with `#[allow(ambiguous_glob_reexports)]` or switch to individual exports
- [ ] If switching, update all consumers that rely on the re-exports
- [ ] Document the decision in a comment or ADR
