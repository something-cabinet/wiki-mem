In canvas-graph.directive.ts, replace hardcoded hex node colors with values from CSS custom properties, and change white stroke to use `var(--ring)` for reliable cross-theme appearance.

## Implementation notes (done 2026-08-08)
- Node colors were already read from `--page-type-*` tokens (prior commit); the remaining hardcoded `rgba(255,255,255,0.3)` halo stroke at the node render loop is now resolved from the `--ring` theme token with `NODE_HALO_ALPHA = 0.3` via `readCssColor('--ring', 0.3)`, with an oklch fallback. `--ring` is `oklch(0.708 0 0)` (light) / `oklch(0.556 0 0)` (dark), so the halo adapts to both themes.
