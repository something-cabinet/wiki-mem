## Bug Description

The Tauri `task_board` command (`commands.rs`) always shows every task as "Draft" in the web UI regardless of the task's actual status in frontmatter.

## Root Cause

`commands.rs:146` in the `read_all_pages` function — the `SimplePageMeta` fallback path parses `simple.status` from frontmatter but hardcodes `status: PageStatus::Draft` instead of using the parsed value. Most task pages don't deserialize as `WikiPageMeta` (missing optional per-type fields like `task_data`), so they hit this fallback and all get `Draft` status.

```rust
// Line 146 in commands.rs — Bug:
status: wm_core::engine::PageStatus::Draft,  // should parse from simple.status
```

## Fix

Replace with:
```rust
status: serde_yaml::from_str::<PageStatus>(&simple.status)
    .unwrap_or(wm_core::engine::PageStatus::Draft),
```

This uses the parsed `simple.status` string and falls back to `Draft` only if the status string itself is invalid.
