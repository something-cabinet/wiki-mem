Replace every custom `wm-` component and every raw-Tailwind UI pattern in the Angular web UI with [Sim UI](https://simui.dev) equivalents. Sim UI is an Angular component library built on Spartan UI + Tailwind CSS. Components that do **not** exist in Sim UI (sidebar, sheet, tooltip, spinner, graph canvas) keep their current implementation.

## Rationale

The project currently has a mix of:

1. Custom `wm-` wrappers (`wmBtn`, `wmInput`, `wmDialog`, `wmSelect`, `wmBadge`, `wmCard`, `wmAccordion`)
2. Raw Tailwind UI blocks (error divs, result cards, task cards, empty states, dark mode button)
3. Spartan helm components (`hlmSidebar`, `hlmSheet`, `hlmTooltip`)
4. One custom WebGL graph directive

Sim UI provides production-ready versions of most `wm-` components with 10–55 variants each, eliminating maintenance burden while improving visual polish.

## What Stays (No Sim UI Equivalent)

| Component | Reason |
|---|---|
| `hlmSidebar` + sub-components | Sim UI has no sidebar component |
| `hlmSheet` + sub-components | Sim UI has no sheet/drawer |
| `hlmTooltip` | Sim UI has no tooltip |
| `wmSpinner` | Sim UI has no spinner component |
| `CanvasGraphDirective` (`@ui/graph`) | Custom WebGL graph — not a UI component |
| `@ng-icons/lucide` | Sim UI uses the same icon library |
