  ## Investigation Summary

  Broken `@wiki/tasks/` references had two root causes:

  1. **57 files** used `task-<id>-<description>.md` but wiki refs used just `<id>` — these were fixed by renaming files to `<id>.md`
  2. **162 files** still use description-only filenames (e.g., `add-aria-expanded-to-...md`) with no short ID — these files have no `knowns_id` in frontmatter

  All 57 renamed files had `knowns_id` in their frontmatter. The remaining 162 don't.

  ## Requirements

  ### FR-1: Assign short IDs to remaining 162 task files
  - Add `knowns_id: <random-id>` frontmatter to each file
  - Rename file from `<description>.md` to `<id>.md`
  - Or: generate IDs from filename hash

  ### FR-2: Update any wiki references pointing to old filenames
  - Scan all wiki pages for references to old filenames
  - Update to new short-ID filenames

  ## Acceptance Criteria

  - [x] All 226 task files use `<id>.md` naming
  - [x] Zero broken `@wiki/tasks/` references across the wiki
  - [x] Zero broken `@wiki/*` references across all specs, patterns, decisions, concepts, rules
