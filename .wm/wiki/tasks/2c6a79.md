## Objective
Wire the wm-mock-server IPC adapters (`registerTauriMocks`, `installHttpInterceptor`) into the WebdriverIO test setup so E2E tests run against mock data rather than requiring a running backend.

## Context
The WebdriverIO config (`wdio.conf.ts`) and sample test (`e2e/graph.test.ts`) exist but use inline `browser.mockIPC()` calls. The wm-mock-server package has reusable adapters for registering all mocks at once from the existing stub JSON files.

## Resolution: CANCELLED — target runtime deleted
- WDIO was removed from the repo (`apps/wm-web` no longer ships WDIO; no
  `wdio.conf.ts` or `e2e/graph.test.ts` exist).
- Tauri was deleted, so `registerTauriMocks` / `@wdio/tauri-service` / mock IPC
  are obsolete.
- CodeceptJS (`apps/wm-web-e2e`, which `mock-manager_helper.ts` targeted) was
  deleted per task b336c7.
- The e2e direction moved to the HTTP-API suite (see mini-ADR in task 23138a).

## Implementation Notes
- `packages/wm-mock-server` itself remains (out of scope), but its only
  consumers were the deleted wm-web-e2e harness; `registerTauriMocks`
  (`src/ipc/tauri-mock.ts`) is now orphaned legacy code. A follow-up cleanup
  can retire the package.
