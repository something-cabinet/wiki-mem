  # Fix: ApiService `updatePage`/`deletePage` payload mapping mismatch

  ## Description

  The `ApiService` in `apps/wm-web/src/app/services/api.service.ts` wraps arguments in `{ payload: { ... } }` for `updatePage` and `deletePage` commands:

  ```ts
  updatePage(id, fields) => this.tauriCmd('update_page', { payload: { id, ...fields } })
  deletePage(id) => this.tauriCmd('delete_page', { payload: { id } })
  ```

  The Tauri backend commands (`create_page`, `search`) expect a `payload` struct, but `update_page` and `delete_page` may expect flat arguments. Verify the backend signature matches the frontend call pattern.

  ## Location

  - `apps/wm-web/src/app/services/api.service.ts`
  - `apps/wm-web/src-tauri/src/commands.rs`

  - [ ] Ensure payload wrapper matches what backend expects
  - [ ] If mismatch, fix frontend or backend to agree on the shape
  - [ ] Run e2e tests to confirm correct data flow
